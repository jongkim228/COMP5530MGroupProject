# Agile, GitHub and Scrum

- **Date:** 30 October 2026
- **Decision:** Use Agile Scrum with two-week sprints, a shared GitHub repository,
  Kanban board and wiki.
- **Alternatives considered:** No agreed process or a non-iterative waterfall plan.
- **Reason:** The project has interconnected tasks and uncertain supervisor
  requirements. Small MVP increments allow early integration and regular evidence.
- **Additional decision:** Scrum Master responsibility rotates, with Kavisha first.


# Hard-Coded MVP for Planning

- **Date:** 30 October 2026
- **Decision:** Task 5 may use hard-coded plans for the MVP instead of blocking on
  live LLM output.
- **Alternatives considered:** Waiting for an integrated LLM before implementing
  other tasks.
